# vidatu-site

The one-page website for vidatu.com. Plain HTML and CSS, no build step. Hosted on GitHub Pages from the `main` branch.

- `index.html`: the whole page.
- `img/`: character stills and the Oob loop, cut from the videos (see the `vidatu` repo).

To point vidatu.com here: add the domain under Settings → Pages, then add the DNS records GitHub shows.
